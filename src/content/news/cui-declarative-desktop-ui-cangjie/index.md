# CUI Brings Declarative Desktop UI to Cangjie

Desktop GUI is one of the quietest corners of the Cangjie ecosystem.
CUI is a community framework that brings declarative UI and reactive state to Windows, macOS and Linux, drawing every pixel itself through SDL.
